# 兴趣画像

优先关注这些方向：

- base LLM、本体模型能力、预训练与模型设计
- LLM 微调、对齐、偏好优化、后训练、推理时增强
- 围绕 LLM 的实验室工作流、工程实验、容易复刻的小场景
- agent 构建、tool use、planning、memory、multi-agent orchestration
- RAG、检索、索引、长上下文、上下文压缩、上下文工程
- 信息检索、搜索、推荐（搜推）、数字图书馆、图书馆学等和 LLM/agent 有明确连接的工作
- 数字人文，只要方法或问题设置对 LLM/agent 有可迁移价值
- LLM 与心理学、人文、社会、教育、辅助决策相关的应用
- LLM 与神经科学、认知科学、脑机接口等交叉方向
- mechanistic interpretability 及相邻议题：SAE、model editing、RepE、causal abstraction、circuit analysis
- test-time scaling、inference-time compute、reasoning-time adaptation
- world model，只要它和语言模型或一般推理能力有明确连接
- audio + LLM、speech + LLM、audio-language model、语音交互
- 其他领域迁移到 LLM 的工作，只要方法论可借鉴

通常不优先：

- 强依赖机器人硬件的工作
- VLA、实体交互、真实操作环境强绑定的系统
- 很偏 CV、和 LLM/agent 没有实质连接的论文
- 纯数学
- 纯理论、缺少明确应用或实验落点的工作

筛选偏好：

- 能确认时，优先单位较强、实验扎实、可复现性高的论文
- 优先有 benchmark、代码潜力、模块化思路或可迁移方法的论文
- 避免大量收录同质化 benchmark churn
- 对检索/搜推/图书馆/数字人文方向保持少量但持续关注，不要一口气塞太多弱相关论文
- 最终日报宁可少而精，也不要堆很多弱相关论文


## 选文原则

- 宁缺毋滥。每天优先选 5-10 篇最值得读的论文，而不是为了凑数量覆盖更多弱相关论文。
- 如果当天强相关论文偏少，可以减少篇数，也不要勉强补齐。
